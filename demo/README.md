# 三分钟 Demo 使用说明

这套材料用于 AI4S Future ScienceSkills Hackathon 的三分钟演示。叙事围绕一条可复现证据链展开：研究请求 → D1 来源 → D2 标准化与科学门禁 → D3 交互地图 → 失败边界。

## 文件

- `presentation.html`：16:9 HTML 幻灯片，离线可用；包含逐页讲稿、计时器和真实地图入口。
- `speaker-script.md`：180 秒逐页讲稿、现场动作、删减策略和问答准备。
- `prepare_demo.sh`：使用仓库内 hash 固定的 USGS 真实切片准备现场输出，并运行十五产物校验。

## 演示前准备

从仓库根目录运行：

```bash
bash demo/prepare_demo.sh /tmp/global-geochemical-atlas-live
```

预期看到：

- 请求执行状态为 `partial_success`；这是覆盖与异常背景不足时的诚实科学状态；
- 产物验证状态为 `valid`，错误和警告均为 0；
- 996 条测定全部标准化、全部具有合法坐标、全部完成固定版本 GLiM 匹配；
- 6 个记录级 high/low 候选异常；空间背景不足，因此不输出候选异常区域。

不要在录制时重新下载数据。现场使用仓库内固定切片，网络只会增加不确定性。

## 打开 PPT

可以直接打开 `demo/presentation.html`。若浏览器限制本地相对链接，从仓库根目录启动本地静态服务：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8000/demo/presentation.html
```

快捷键：

- `←` / `→`、`PageUp` / `PageDown`、空格：翻页；
- `N`：显示或隐藏当前页讲稿；
- `T`：启动、暂停或继续三分钟计时；
- `R`：计时归零；
- `F`：全屏；
- `Home` / `End`：首页 / 尾页。

## 建议录制顺序

1. 开始前打开 PPT、`/tmp/global-geochemical-atlas-live/interactive_map.html` 和一个终端；
2. PPT 讲到第 4 页时只展示已完成命令和校验摘要，不等待运行；
3. 第 5 页点击“打开真实交互地图”，筛选一个元素，开启异常候选，点击一个样点查看原值、标准值、方法、QC、来源定位与置信度；
4. 返回 PPT，说明不确定性与失败关闭；
5. 结尾回到“一个请求、五类交付、全链可复核”。

PPT 中的内置地图入口使用四介质、14 个公开来源、796 条观测的固定演示；终端准备的现场输出使用 996 条 USGS 土壤观测验证生产 `n≥20` 阈值。两套切片分别证明“来源与介质广度”和“生产阈值闭环”，不得混写成一个数据集，也不代表全球空间覆盖。

## 录制检查

- 分辨率使用 1920×1080，浏览器缩放 100%；
- 讲稿控制在 180 秒，至少预留 5 秒给页面切换；
- 不展示密钥、私人路径、聊天记录或评测私有材料；
- 不说“发现污染/矿床”，只说“在声明的可比背景组内识别候选高/低值”；
- 不说“全球覆盖”，只说“全球可扩展、当前覆盖可解释”；
- 地图加载失败时留在第 5 页使用已嵌入的真实工作流截图继续讲，不中断录制。
