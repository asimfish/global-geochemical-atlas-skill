# Global Geochemical Atlas Skill：冠军 Demo 讲稿

总时长 180 秒，6 页。HTML 与 PPTX 使用同一叙事；HTML 第 3、4 页可直接操作真实地图，PPTX 使用完整无裁切截图作为稳定后备。

## 0:00–0:20｜第 1 页：颜色没有证据，地图就没有意义

> 先看右侧，这不是效果图，而是我们的 D3 expanded global run。地球化学地图最危险的地方，是颜色很有冲击力，证据却不可核查。我们的目标不是给散点上色，而是把公开测定变成可追溯研究界面：真实运行、离线自包含，并直接面向比赛要求的五类交付。

动作：按 `T` 启动计时。扫描线越过地图后再开始说第一句，建立“真实运行”的第一印象。

## 0:20–0:50｜第 2 页：一个请求，启动证据引擎

> 用户只需要给出元素、区域和样品介质。D1 负责公开来源、版本许可、记录定位符和哈希；D2 用确定性脚本完成单位与基准统一、质量控制、地质背景和稳健 MAD 候选识别；D3 再按 profile 生成地图、证据视图和迭代入口。最终同时得到交互地图、标准数据库、来源与置信度、异常结果和可复用 Skill。高自由度交给 Agent，科学红线交给可测试代码。

动作：沿请求 → D1 → D2 → D3 → 五个输出节点移动光标。不要逐条解释字段。

## 0:50–1:25｜第 3 页：全球真实运行

> 当前 expanded run 有四万四千五百一十条测定成功上图，对应一万一千五百四十八个物理样点、四种介质和五百三十五个 high 或 low 记录候选，界面同时暴露地图、数据库、来源置信度和异常页签。这里的热区只表示采样密度，不是浓度插值；总计四万四千五百三十六条 canonical records，二十六条不可上图记录仍留在数据库和 QC 中。十五个来源是声明来源，不等同于独立核验。

现场动作，控制在 8 秒：

1. 点击“启用地图交互”；
2. 拖动或缩放一次，让评委确认不是截图；
3. 点击“退出地图交互”，继续讲科学限定。

地图未加载时：不排查网络，直接使用已嵌入的 1920×1080 完整截图继续。

## 1:25–1:50｜第 4 页：从全球推入中国

> 同一个 D3 接口继续下钻中国：七千一百一十四条测定、一千四百六十四个物理样点、一百三十六个记录候选，覆盖六个元素和两种介质。范围不是简单矩形框，而是 Natural Earth 国家多边形与 WGS84 bbox 联合严格裁剪，框内邻国记录会被排除。红色 high 和青色 low 只是筛查方向，不能直接解释为污染、矿化或成因。

动作：指向黄色国界、high/low 图例和红色限定语。时间充裕时再启用中国地图交互，不强制操作。

## 1:50–2:30｜第 5 页：可信，不是永远给答案

> 零点八七四是工作流可用性的置信度，不是百分之八十七点四的正确概率；五百三十五个记录候选，也不是五百三十五个成因结论。五个分量分别是来源零点八九七、完整性零点九五六、方法零点八一三、空间零点八零零、质量控制零点八七六。系统同时把失败边界做成可见结果：二百四十八条删失观测绝不补成零，二十六条不可上图记录仍可审计；expanded slice 的 locator 覆盖率是百分之百，但 independent verified count 仍然是零，所以证据等级不升级。D3 只呈现 D1 和 D2 的证据，不重新计算科学结论。

动作：先指两条“≠”，再从左到右扫过五分量，最后停在三条护栏。

## 2:30–3:00｜第 6 页：一个请求，五类交付，全链可核查

> 最后请记住一句话：一个请求，五类交付，全链可核查。交互元素分布地图、标准化地球化学数据库、数据来源与置信度说明、异常区域识别结果和可复用 Skill 文档，都由同一个稳定接口交付。当前运行证明是十五个声明来源、四万四千五百三十六条 canonical records，以及全球和中国两个真实视图。打开、检查、追溯、复现，这就是 Global Geochemical Atlas Skill。

动作：五个节点出现后再说五类交付；最后四个英文动词落下时停顿一秒，不再翻页。

## 现场控制

- `N`：显示或隐藏当前页讲稿。
- `T`：启动或暂停 3 分钟计时；`R`：归零。
- `F`：全屏。
- 第 3、4 页：点击“启用地图交互”；按 `Esc` 或再次点击按钮退出。

## 口径边界

- `15 declared sources` 只表示 D2 输出中的来源声明，不说“15 个已独立验证来源”。
- `535` 与 `136` 是记录级 high/low 候选，不说污染、矿化、矿床或成因。
- 密度层只表达采样密度，不插值元素浓度。
- `0.874` 是五分量工作流可用性置信度，不是正确概率。
- `44,536 canonical records`、`44,510 mapped measurements`、`11,548 physical samples` 是三个不同口径，不混写。
- 本 Demo 的 expanded run 与 `prepare_demo.sh` 的 996 条 USGS 生产阈值切片是两套验证资产，不合并统计。

## 常见追问

### 数据库格式是不是自创的？

内部采用一行一个“样品 × 元素测定”的规范长表，保留原字段、单位与基准、来源定位、分析方法、QC、地质匹配、异常上下文和五分量置信度；同时提供 EarthChem/GEOROC、USGS NGDB、GEMAS、GEMStat 等专业平台字段 crosswalk。稳定内部 schema 负责可测试性，crosswalk 负责专业互操作，二者不互相替代。

### AI 在哪里？

Agent 负责理解研究请求、路由来源、选择适用工作流、解释失败和组织交付；单位换算、schema 校验、QC、统计检验和哈希绑定由确定性代码执行。

### 为什么不直接做全球插值？

当前公开来源的覆盖、采样设计和分析方法不均衡。对空白区直接插值会把数据缺口伪装成连续知识，因此默认展示观测覆盖；空间预测必须另行声明模型、验证和不确定性条件。
