# D1 下载与缓存测试记录

> 2026-08-05 的早期哈希验收记录已被 V4 政策取代。当前流程不计算、读取、更新或校验 MD5/SHA 内容哈希，也不把哈希用于来源准入、缓存命中、评分、测试或交付验收。

## 当前缓存身份契约

缓存复用按以下可读信息共同判断：

- `source_id` 与 DOI/PID；
- dataset version、release date 和 access time；
- file ID、文件名、字节数和成员清单；
- schema、行数和关键分类统计；
- 许可、科研使用条件和精确获取参数。

任一关键字段漂移时，只重建受影响来源并重新生成覆盖汇总；没有变化的来源分区直接复用。历史哈希字段允许存在于旧文件中，但新代码不读取或更新。

## 运行模式

| 模式 | 默认用途 | 数据行为 |
|---|---|---|
| fixture | 普通测试、演示和接口验证 | 使用仓库内小切片，不下载全量数据 |
| cached | 日常离线/增量运行 | 复用身份契约一致的来源分区 |
| online | 明确要求刷新相关来源 | 只获取本次请求涉及的来源 |
| full release | 显式发布、覆盖审计或验收 | 重放全部 26 来源并可构建全量 SQLite |

正常使用、来源准入和普通测试不要求下载或持有 4,096,615 条本地数据库。全量能力必须可重放，但只在显式 full release/acceptance 模式执行。

## 当前必测场景

执行：

```bash
python skills/global-geochemical-atlas/scripts/component_test.py --component d1
python skills/global-geochemical-atlas/scripts/self_test.py
```

覆盖以下行为：

- 在线冷启动、按需来源获取和缓存复用；
- 断网 fixture/缓存重放；
- URL、DOI/PID、版本、文件身份、字节数、成员清单、schema、行数和关键统计漂移；
- HTML/XHTML 冒充数据文件、体积超限、超时和 HTTP 错误；
- ZIP 损坏、必要成员缺失、路径穿越和必要字段缺失；
- 单来源变化只重建一个来源，无变化不重新解析；
- 部分来源失败时返回明确状态，要求全源时失败关闭；
- 原始记录、来源定位、单位、qualifier、方法和关系表可回溯。

## 故障期望

| 故障 | 期望行为 |
|---|---|
| 离线且缓存缺失 | 返回 `network_unavailable` |
| DOI/PID、版本或文件 ID 不一致 | 拒绝复用该来源缓存 |
| 字节数、成员、schema、行数或关键统计漂移 | 标记 drift 并只重建该来源 |
| HTML/XHTML 响应 | 写正式文件前拒绝 |
| 声明或实际体积超限 | 中止，不发布部分文件 |
| HTTP 403 | 返回 `source_not_accessible` |
| 可重试服务错误 | 按有界退避重试 |
| ZIP 损坏或缺成员 | 拒绝并保留明确失败原因 |
| 表间数量无法解释 | 触发来源红线，不发布解析结果 |

## 证据边界

缓存一致只证明工程重放条件满足，不证明测量值天然正确。科学可信性仍由出版者、版本、原始记录定位、介质、方法、单位、QC、引用、30 条 Codex 结构化自动审计和适用边界共同表达。
