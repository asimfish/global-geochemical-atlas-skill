标准化地球化学数据库

完整交付物是同目录下的 geochemistry.csv；页面预览仅使用当前 HTML 内嵌的可上图记录，不会丢弃完整 CSV 中的无坐标、坐标 QC 失败或区域范围外记录。

数据库语义

一行 = 一个样品的一项元素测定，不是一个物理采样点。字段同时保留原始值 / 单位 / qualifier 与标准值 / 单位，并绑定样品类型、measurement basis、地质单元、分析方法、WGS84 坐标、来源定位、QC flags 和五分量置信度。多元素样品会有多行，不能直接把记录行数当成采样点数。

元素组合与共测关系

散点只使用同一样品、同介质、同 basis、同方法组且单位各自一致的最大可比子组；共测不等于相关，更不构成因果或地质成因结论。区域范围继承地图选择。

数据来源与置信度说明

置信度直接消费 D2 报告，来源证据直接消费 D1 manifest；D3 不重算、不补齐。置信度衡量记录对本工作流的可用性，不是正确概率、统计置信度或准确率。
