标准化地球化学数据库

完整交付物是同目录下的 geochemistry.csv；页面预览仅使用当前 HTML 内嵌的可上图记录，不会丢弃完整 CSV 中的无坐标、坐标 QC 失败或区域范围外记录。

数据库语义

一行 = 一个样品的一项元素测定，不是一个物理采样点。字段同时保留原始值 / 单位 / 限定符与标准值 / 单位，并绑定样品类型、测量基准、地质单元、分析方法、WGS84 坐标、来源定位、QC 标志和五分量置信度。多元素样品会有多行，不能直接把记录行数当成采样点数。

元素组合对比

这个页面回答一个明确问题：在指定区域范围、同一批可比样品中，两种元素是否一起升降？每个散点代表同一物理样品中的一对测定；矩阵只回答“哪些元素经常被共同测量”。对比区域与地图双向同步。

可比样品配对散点 · log10

虚线是两轴样本中位数，帮助观察高-高、低-低与反向象限；Spearman ρ 描述单调关联，不证明因果。

元素共测覆盖矩阵

数字是当前区域和介质中同一采样身份同时具有两元素记录的数量，仅用于选择有足够覆盖的组合。点击非对角单元格切换散点；矩阵不代表相关强度。

数据来源与置信度说明

置信度直接消费 D2 报告，来源证据直接消费 D1 manifest；D3 不重算、不补齐。置信度衡量记录对本工作流的可用性，不是正确概率、统计置信度或准确率。
