## 一句话说明

继续尽可能扩大全球地球化学信源目录，同时把岩石、土壤、沉积物和水体各做出一个真实、可追溯、可运行的端到端样板；来源证据越完整，置信度越高，但不再因为缺少某一项证据就把仍有价值的数据全部丢弃。

## 一、V3 已确认的核心决定

### 1. 不再把全部质量检查当成二元硬门

V2 使用“全部通过才能批准”的思路，适合建立安全基线，但不适合表达真实科研数据的渐进可信程度。V3 改为：

- 每项证据独立记录为 `verified / partial / missing / conflict / not_applicable`；
- 通过的证据越多，来源证据分越高；
- 缺少版本 DOI、适配器、30 条人工复核或部分方法字段时，不自动否定整个来源；
- 低置信度数据可以保留、查询和展示，但必须携带缺失项、限制和适用范围；
- 是否能参与标准化、跨源比较或异常分析，由记录级方法可比性和 D2 规则继续判断；
- 置信度是“证据完整程度”，不是“这个数值有多少概率为真”。

### 2. 科研使用条件与科学置信度分开

“许可违法”不是准确术语，V3 统一改写为“科研使用条件不明确”或“需要确认科研使用授权”。本项目的目标是科研分析和来源引用，不是改编或重新分发第三方原始数据库。

- 数据能查看或下载后，仍要确认是否允许用于本次科研分析、是否仅限非商业科研、是否要求署名或需要单独申请；
- CC BY 允许科研使用，但要求适当署名、链接许可并说明对材料所做的处理；
- CC BY-NC 与本项目的非商业科研场景通常更接近，但仍要保留非商业限制和署名条件；
- 未找到明确许可不等于违法，只表示当前尚未确认科研使用条件；
- 绕过登录、付费、表单、访问控制或明确禁止的自动抓取，不属于本项目允许的获取方式。

完整第三方原始文件只进入本地只读缓存，不提交 Git，也不作为比赛产物重新发布。比赛输出是本次科研任务的标准化查询结果、分析结果、地图、来源引用和置信度说明，不是原数据库镜像。

V3 分别输出：

1. `research_use_status`：是否允许本次科研分析，以及署名、非商业或申请条件；
2. `source_evidence_score`：来源、版本、文件、方法和复核证据有多完整。

科研使用条件不作为科学可信度分数的一部分。它决定系统能否在本次任务中获取和分析数据，而不是判断测量值是否准确。

- [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)

### 3. 允许动态 API 响应形成可复现快照

已经确认：MarChem 这类没有对应不可变 DOI 的动态服务，可以使用“官方 API 响应 + 精确请求 + 获取时间 + SHA-256 + 文件清单”形成固定快照。

动态快照不冒充发布方 DOI，也不覆盖旧快照。它的版本证据通常低于发布方不可变 DOI，但高于没有时间、参数和 hash 的临时下载。

### 4. 广度与深度同时推进

V3 同时维护两条主线：

| 主线 | 目标 | 完成判断 |
|---|---|---|
| A：信源广度 | 继续补亚洲、非洲、南美、墨西哥、太平洋岛国及州/省级调查等空白 | 每轮发现均有搜索渠道、证据、区域覆盖和上游重复关系记录；不提前宣称全球完整 |
| B：四介质深度 | GEOROC 岩石、USGS 土壤、MarChem 沉积物、GEOTRACES 水体跑通完整工作流 | 每条样板从请求、获取、快照、适配、schema、QC、置信度一直到交互地图和来源追溯均可复现 |

信源目录不必等到发现饱和才开始样板；四介质样板也不能取代持续补源。

## 二、对赛题的最终交付理解

本项目不交付一个“全球每个位置、所有介质、所有元素都有实测值”的数据库。最终交付的是一个证据优先的联邦式 Skill：

```text
用户请求
  ├─ 元素
  ├─ 区域 / bbox / 地质单元
  ├─ 岩石 / 土壤 / 沉积物 / 水体
  └─ 时间、方法、科研使用条件与记录数要求
       ↓
来源发现与路由
       ↓
官方文件 / API / DOI 数据快照
       ↓
来源适配、记录对账与证据评分
       ↓
统一归档 schema + 原始观测长表
       ↓
D2 单位、方法可比性、QC 与异常候选
       ↓
D3 实测点、覆盖空白、置信度和异常图层
       ↓
一个完整、可复用的主 SKILL.md
```

赛题中的“全球图谱”解释为“尽可能全面的全球公开观测数据及其覆盖空白”，不是连续实测表面。插值或模型预测必须与实测点分层展示。

赛题中的“污染区域识别”使用两级表述：

- `geochemical_anomaly_candidate`：相对可比背景的异常高值或低值；
- `possible_anthropogenic_signal`：除异常外，还有表层/深层差异、潜在排放源、时间变化或多污染物组合等额外证据。

只凭元素高值不能直接写成污染、矿化或因果结论。

## 三、V3 的分级使用模型

### 3.1 不再只有“批准/不批准”

来源和数据处理过程拆成四个相互独立的状态：

| 状态 | 回答的问题 | 示例 |
|---|---|---|
| `access_status` | 当前能否按正常方式访问 | open、account_required、application_required、restricted、unavailable |
| `research_use_status` | 能否用于本次科研分析，需要什么条件 | open_research、attribution_required、noncommercial_research_only、permission_required、unknown |
| `evidence_tier` | 来源和处理证据完整到什么程度 | A、B、C、D、U |
| `use_mode` | 当前可以用于什么 | discovery、raw_observation、normalized_analysis、benchmark_ready |

同一来源可以具有较高科学证据，但科研使用需要申请；也可以允许开放科研使用，但方法字段不全、证据等级较低。两者不能合成一个模糊的 approved 状态。

### 3.2 只有少数操作边界，不称为质量硬门

以下情况决定“当前能执行什么操作”，而不是用于给科学可信度打分：

- 不绕过访问控制或需要额外授权的流程；
- 不绕过来源声明的科研使用、署名、非商业或申请条件；
- 文件损坏、响应截断或分页不完整时，不把残缺内容伪装成完整数据；
- 来源完全无法识别时，只能保留为未验证线索，不能把其中数值表述为已确认观测。

这些数据和线索不必从目录删除，但必须降到相应的 `use_mode`。

### 3.3 来源证据分

首版 `source_evidence_score` 使用八个维度，总分 100：

| 维度 | 权重 | 满分证据 |
|---|---:|---|
| 身份与发布者 | 10 | 标题、发布者、官方落地页和稳定标识明确 |
| 版本或快照 | 15 | 不可变 DOI/发布版本，或完整的内容寻址动态快照 |
| 文件与记录完整性 | 15 | 文件成员、hash、分页和原始/解析/拒绝/失败数量对账 |
| 来源追溯 | 15 | 可回到数据集、文件、行列/API 记录、样品和原始引用 |
| schema 语义 | 15 | 样品、介质、分析物、值、单位、坐标和测量基准可解释 |
| 方法与 QC 元数据 | 10 | 消解/提取、仪器、实验室、检出限、不确定度和 QC 可用 |
| 适配器与复现测试 | 10 | 固定版本/快照可重复解析，字段映射和数量对账有测试 |
| 人工复核 | 10 | 至少 30 条分层人工回看通过并保存证据；不足 30 条时全量 |

每项状态按以下系数计分：

```text
verified       = 1.0 × 权重
partial        = 0.5 × 权重
missing        = 0
conflict       = 0，并单独输出冲突
not_applicable = 从分母移除，并说明理由
```

人工复核采用渐进分数：

| 完成情况 | 人工复核维度建议分 |
|---|---:|
| 未开始 | 0/10 |
| 1–9 条 | 2/10 |
| 10–29 条 | 5/10 |
| 30 条分层复核通过，或不足 30 条时全量通过 | 10/10 |
| 发现未解决的系统性映射错误 | 0/10，并记录 `conflict` |

适配器和 30 条人工复核不是所有来源进入目录的硬门，但四介质比赛样板必须完成，才能标记为 `benchmark_ready`。

### 3.4 证据等级

| 等级 | 分数 | 解释 |
|---|---:|---|
| A | 85–100 | 证据链完整，可作为高置信度样板 |
| B | 70–84 | 主要证据完整，仍有明确限制 |
| C | 50–69 | 可用于带限制的分析或补覆盖，不宜单独支撑强结论 |
| D | 1–49 | 主要用于探索、原始观察或发现上游来源 |
| U | 无法评分 | 信息不足，仅保留发现线索 |

等级阈值先作为可审阅默认值。报告必须同时展示各维度，不能只展示总分。

### 3.5 四种置信度不能混成一个数

最终结果分别报告：

1. `source_evidence_score`：D1 来源证据完整度；
2. `record_quality_score`：D2 单条测定的方法、单位、QC 和坐标质量；
3. `coverage_status`：地区 × 介质 × 元素 × 时间 × 方法的覆盖程度；
4. `anomaly_support`：背景样本、统计稳健性和独立证据对异常候选的支持程度。

权威来源不等于空间覆盖全面，覆盖全面也不等于每条测量都可比较。

## 四、动态快照政策

### 4.1 快照最小证据

动态 API 或下载服务的快照至少记录：

- `source_id`；
- 完整请求 URL、HTTP 方法和精确参数；
- UTC 获取时间；
- 服务端返回的生成时间或更新时间；
- 响应状态、类型和字节数；
- 原始响应 SHA-256；
- 归档全部成员的文件名、大小和 SHA-256；
- 请求范围与实际返回范围；
- 原始记录数、解析数、拒绝数、失败数；
- 获取脚本和适配器版本；
- 许可、署名和引用；
- 已知限制与复核状态。

快照 ID 建议：

```text
<source_id>:<observed_utc>:<sha256前12位>
```

### 4.2 存储规则

- 原始第三方完整文件进入仓库外的只读内容寻址缓存；
- Git 提交快照 manifest、hash、字段统计、抽样复核记录和可合法分发的小型 fixture；
- 新快照创建新目录，不覆盖旧快照；
- 相同请求的新响应发生变化时生成 diff，旧证据等级不自动继承；
- 发布方后来提供 DOI 时，把 DOI 与已有快照建立 `replaces / isVersionOf` 关系，不修改历史 hash。

### 4.3 MarChem 已确认快照

本轮已允许使用：

```text
source_id: norway-marchem
observed_at: 2026-08-05T10:27:11Z
archive_sha256: be888784ee2eafd45ab43c036eefbae9e760057d25f64fbc323993e8809ca6c6
physical_rows: 1070
distinct_samples: 880
```

该快照可以进入适配器开发和端到端样板。它不冒充官方 DOI；完成适配器、数量对账和 30 条人工复核后标记为 `benchmark_ready`。

## 五、主线 A：继续扩大全球信源目录

### 5.1 当前基线

截至 V3 制定时：

- 候选目录共 32 个来源；
- 发现轮次为第 3 轮，`saturated=false`；
- 目录中涉及岩石 15 个、土壤 11 个、沉积物 21 个、水体 14 个；
- 这些数字有重叠，也不代表来源已经接入或全球覆盖已经完成；
- 当前主要空白仍为亚洲、非洲、南美、墨西哥、太平洋岛国，以及美国州级和加拿大省级调查。

### 5.2 补源渠道

每个地区与介质至少检查：

1. 全球聚合库和学科数据库；
2. 国际组织和国际合作计划；
3. 国家、州、省、领地地质调查和环境/水文机构；
4. 海洋、湖泊、土壤和样品馆藏系统；
5. 可信 DOI 仓库和数据论文；
6. 聚合平台指向的上游原始项目；
7. 论文附件、公开表格和项目归档。

PDF 和扫描件可以进入发现目录；数值自动抽取作为后续能力，默认进入低置信度隔离区和人工复核，不直接混入样板。

### 5.3 优先级计算

新增来源不按知名度或记录数单独排序，而按以下因素综合：

```text
边际覆盖收益
× 来源独立性
× 结构化接口可用性
× 方法与 QC 元数据完整度
× 版本/快照可复现性
× 当前科研使用条件适配度
÷ 接入和维护成本
```

科研使用状态不参与科学证据分，但会影响当前任务是否可以自动获取和分析该来源。

### 5.4 覆盖状态

覆盖矩阵升级为：

```text
区域 × 介质 × 子介质/分相 × 元素 × 时间 × 方法 × 证据等级
```

状态继续使用：

- `covered`：有足够可用记录和明确适用范围；
- `partial`：存在数据，但空间、时间、元素、方法或证据等级有限；
- `unknown`：检索、复核或上游血缘尚未完成；
- `uncovered`：完成充分检索仍未找到；
- `restricted`：发现数据，但当前科研使用条件不适合请求或仍需申请。

信源数量增加不能自动把 `unknown` 改成 `covered`。

### 5.5 每轮发现交付

- 更新 `source_catalog.json`；
- 追加 `source_discovery_log.jsonl`；
- 更新 `source_discovery_scope.json`；
- 更新覆盖矩阵、血缘报告和优先级报告；
- 标记新增来源与现有来源的上游重复关系；
- 给出本轮新增高价值来源、无新增原因和下一轮区域；
- 继续以连续两轮无新增高相关来源作为“发现趋于饱和”的必要条件，但不声称永久完整。

## 六、主线 B：四介质端到端样板

| 水体 | `geotraces-idp2025` | DOI、许可和产品元数据已验证；BODC 归档仍在准备 | 获取固定归档或可冻结官方子集，完成分相/QC/贡献者映射、30 条人工复核和海水地图 |

四个来源都是“工作流样板”，不代表各介质已经全球覆盖。GEOROC 太古宙、USGS 美国土壤、MarChem 挪威海域和 GEOTRACES 航线覆盖必须在地图中明确显示。

### 6.2 每条路线的统一步骤

1. 冻结用户请求；
2. 路由到来源并解释选择原因；
3. 获取固定发布或动态快照；
4. 保存请求、响应、hash、许可和引用；
5. 用来源适配器解析原始事实；
6. 对账原始总数、目标行、拒绝行和失败行；
7. 映射到 D1 分层 schema；
8. 准备并完成人工分层回看；
9. 计算来源证据各维度和等级；
10. 交给 D2 做单位、删失值、方法可比性和记录 QC；
11. 交给 D3 生成实测点、覆盖空白、置信度和异常候选图层；
12. 从任意地图点回溯到原始值、文件/API 记录、方法和引用；
13. 生成一次可重复运行的最终报告和主 Skill 示例。

- 明确美国本土样板不能代表全球土壤。

### 6.5 沉积物样板：MarChem

适配器必须解决：

- 1,070 个物理行与 880 个不同样品的关系；
- 两个参数组导致的 190 个重复样品行；
- 每个样品只有一条 As/Cu/Ni/Zn 目标元素行；
- `Batch_code` 与参数级方法表的连接；
- 干重 `mg/kg`；
- `<` 删失值与批次级 LLQ；
- 7 M HNO3 部分消解，不代表总含量；
- accredited 与 not-accredited 批次；
- 深度切片、站位、航次和样品的稳定 ID；
- 动态快照 ID、原始文件成员和观测 hash。

30 条人工复核覆盖正常、缺失、删失、重复样品、早期未认可批次、极值和空间边界。

### 6.6 水体样板：GEOTRACES IDP2025

首选 BODC 官方归档；如果归档持续未准备完成，可以使用官方 WebODV 或其他官方子集接口，但必须按动态快照政策冻结精确请求和响应。

适配器必须保留：

- 航次、站位、采样时间、经纬度和深度；
- 离散海水、传感器、降水、气溶胶和冰冻圈数据包的边界；
- As/Cu/Ni/Zn 的参数代码；
- dissolved、particulate 等分相；
- 原始单位、QC flags、1-sigma 误差和检出限；
- 采样系统；
- 数据贡献者、方法和原始出版物；
- DOI 与 Fair Data Use 引用要求。

30 条人工复核按海盆、航次、深度、分相、QC 状态和目标元素分层。海洋航线之间的空白必须保留，不能画成规则全球观测网格。

## 九、主 Skill 文档要求

## 十三、风险与应对

| 风险 | V3 应对 |
|---|---|
| 把软评分理解成低质量数据都能直接比较 | 保留数据不等于允许所有分析；D2 继续按方法、单位、分相和 basis 决定可比性 |
| 总分掩盖关键缺失 | 强制展示八个维度和 evidence；总分不能单独出现 |
| 科研使用条件和科学可信混为一谈 | 独立输出 research use status 与 source evidence score |
| 动态快照被误写成官方版本 | 使用自有 snapshot ID，明确 `dynamic_api_snapshot`，不冒充 DOI |
| 30 条复核被误解为全量质量证明 | 同时做全量 hash、schema、数量和关系对账；30 条只检查人工字段映射 |
| 四介质样板被误解为全球覆盖 | 每张地图同时展示实际范围、样点密度和空白 |
| 只扩目录、不做可运行结果 | 四介质主线有独立里程碑和统一输出包 |
| 只做样板、停止补源 | 信源发现作为贯穿所有里程碑的并行主线 |
| 高值被直接解释成污染 | 只输出异常候选；污染信号需要额外空间、时间和来源证据 |
| 最终文档过于分散 | 内部多文件，外部一个完整主 `SKILL.md` |

## 十六、计划边界

V3 追求“尽可能全面、证据透明、可以运行”，不承诺绝对完整或绝对真值。任何来源、记录、地图和异常结论都必须能说明：

- 数据来自哪里；
- 当前允许怎样使用；
- 哪些证据已经具备；
- 哪些字段或方法仍然缺失；
- 覆盖到哪里、哪里没有数据；
- 哪些结果是实测、哪些是标准化、哪些是统计候选、哪些是模型推断。

这套边界本身是最终 Skill 可信和可复用的一部分。
