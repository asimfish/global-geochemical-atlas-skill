# Skill uplift 对照实验说明

使用两个全新、相互隔离的 Qwen3.8-Max 会话和空目录。分别原样发送
`QWEN_WITH_SKILL_PROMPT.md` 与 `QWEN_NO_SKILL_PROMPT.md`。两组必须使用同一仓库 commit、同一机器资源、网络策略、
最多三轮修正和同一 scorer。不要把第一组的产物、错误信息或经验发给第二组。

比较：

- 主指标：最终 `score.json.score`，uplift = with_skill − no_skill；
- 次指标：首轮分数、达到 70 分所需轮次、扣除下载后的总耗时、失败检查数量；
- 科学红线：伪造来源未报告字段、删失值被当精确值、水体误赋陆地岩性、异常被写成污染/矿化结论；
- 工程指标：能否由 `run.sh` 重建、离线地图是否自包含、输出是否完整。

只有主指标更高且科学红线没有恶化，才可宣称 Skill 带来正 uplift。两个会话的模型服务版本或 commit 不同则实验无效，
应重跑而不是人工校正分数。
