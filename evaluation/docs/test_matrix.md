## 设计约束

- Public、Shadow、Final 各 8 题，但不是简单同题换数字；隐藏集合使用未公开编码组合和交互失败模式。
- 至少 80% 的单题分数来自确定性检查；开放科学解释最多 20%，并必须引用运行产物中的具体字段或记录。
- 每题至少包含一个“正确拒绝或降级”条件，避免只奖励无条件生成结果。
- 合成 fixture 只测试处理逻辑，不被用作真实地球化学背景结论。
