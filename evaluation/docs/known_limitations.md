## 仍未完成，因此不能声称“正式盲测已交付”

1. **没有被测 Skill 和裸模型运行**：当前只有 gold smoke，不是 blind raw results。
2. **没有官方模型冻结参数和沙箱镜像 ID**：不能生成可比较的 uplift。
3. **当前 Final 已失去严格 holdout 资格**：旧题曾出现在公开 Git 历史中；迁出只能用于隔离回归资产，正式比赛必须另行生成、私下冻结并签名新的 Final。
4. **数值处理题以可审计的合成 adversarial fixture 为主**：真实来源范围使用官网元数据核验，但尚未嵌入一个经许可、带原始下载哈希的真实数值数据子集。冻结前建议增加真实 USGS 或 GEOROC 小快照作为补充回归层；不得把人工数值包装成真实地区背景。
5. **LLM rubric 尚未在目标 grader 上做一致性标定**：需用至少一组高、中、低质量锚定答案验证双评差异和人工复核阈值。
6. **本地 `0700` 仍不是完整赛事权限模型**：正式执行应由独立评测身份持有私有根目录，并记录只读挂载和访问审计。

## 推荐冻结顺序

1. 评测组科学复核 fixture、公式、gold 和红线；
2. 加入至少一个真实公开数值数据小快照并记录许可、URL、访问日期、原始哈希、筛选脚本和派生哈希；
3. 用参考实现和 3–5 个故障实现跑 checker，确认既能判对也能抓错；
4. 标定 LLM grader；
5. 冻结任务权重、模型参数、沙箱、Skill 版本和评测包 manifest；
6. 先运行 Shadow，功能冻结后才运行 Final；
7. 保存全部原始日志，再生成汇总和科学验收报告。
