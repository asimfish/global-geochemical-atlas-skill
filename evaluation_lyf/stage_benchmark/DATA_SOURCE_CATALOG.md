# 全球地球化学数据源补充路线

“全球”不能靠把稀疏点铺满底图来伪装。当前策略把来源分成四类：已冻结进基准、可在运行时接入、仅用于发现、受许可或坐标隐私限制。机器可读版本在 `contracts/global-source-catalog.json`。

## 已接入扩展基准

- 中国：TPDC 中国山地土壤，1,314 个真实观察，覆盖 30 个山地和三种层位。
- 非洲：AfSIS 18 个国家标签的土壤湿化学；PANGAEA 北非细粒土壤补足撒哈拉—萨赫勒。
- 欧洲与小国：FOREGS 同时覆盖 topsoil、subsoil、humus、stream water、stream sediment、floodplain sediment；按国家与介质设上限，小国样品全部保留。
- 日本：GSJ 全国河流沉积物，七个目标元素均可用。
- 原核心基准继续提供 GEOROC 全球岩石、GEMAS 欧洲农业土壤、NGSA 澳大利亚沉积物 Hg 和 GEMStat 35 国水体。

扩展后共有 15 个独立来源数据集、102 个显式来源国家/地区标签。这个数字包含源保留代码和名称，不能直接解释为 102 个去重主权国家。

## 下一批优先接入

| 优先级 | 来源 | 主要填补 | 接入前必须解决 |
|---|---|---|---|
| P0 | 加拿大 CDoGS | 北美土壤、沉积物、水 | 逐调查下载、方法字段统一、重叠样品去重、许可核验 |
| P0 | Brazil GeoSGB/GEOQ | 南美土壤/沉积物/岩石 | 找到稳定批量导出、确认再分发条款与字段字典 |
| P0 | Colombia SGC atlas | 南美区域与小国可见性 | 判断 KMZ 是原始观察还是制图产品，恢复逐行证据 |
| P1 | EarthChem | 全球岩石与矿物 | 按数据集许可、样品身份和分析方法拆分，避免重复 GEOROC |
| P1 | GEOTRACES IDP2025 | 全球海水痕量元素 | 溶解/颗粒相分离，不能与淡水直接合并 |
| P1 | New Zealand PETLAB | 大洋洲岩石 | 数据服务接口、许可、样品—分析表连接 |
| P1 | IUGS national atlas index | 小国家发现 | 每个国家产品的机器可读性与许可独立核验 |
| P2 | China GeoCloud | 中国全国/区域多介质 | 登录、批量下载和再分发条件按数据集处理，禁止默认抓取 |

## 不应默认打包的来源

- Soils4Africa：官方许可对精确采样位置可见性有限制。只能在当前条款允许时做聚合级运行时接入，不能把精确点直接放进公开离线地图。
- 仅有预测栅格的产品：可作为背景层或空间协变量，但不能伪装成原始实验室观察，也不能与 observation 共同计算不加区分的异常阈值。
- 只有论文图、无可追溯表格的来源：可进入发现队列，不能作为数值数据库的证据行。

## 仍然存在的真实空白

- 南美洲的土壤、沉积物和水体仍然稀疏；当前主要是 GEOROC 岩石和少量 GEMStat 水体。
- 北美洲当前基准主要是 GEOROC 岩石与少量水体，尚未接入 CDoGS/USGS 的大规模多介质数据。
- 非洲有岩石与土壤，但开放、许可清晰的沉积物和水体目标元素切片仍不足。
- 南极洲只有文献岩石；不能用插值“补齐”土壤、沉积物或水体。
- 任何国家有一个点都不等于该国被充分覆盖，小国高值也不能在国家平均或粗网格中被抹平。

因此可视化应同时显示点、来源、介质、分析基础、空间密度和“无数据”状态；低覆盖区域保持暗色是诚实结果，不应用模型预测值冒充观察值点亮。
